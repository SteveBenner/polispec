# Roadmap

Planned work, not yet built. Nothing here is a commitment to a release.

## Smoke tests

- Ship a bundled smoke-test suite: scenario definitions for each `specs/app.yml` coverage unit, a scratch-project fixture builder, headless harness runners, and deterministic checkers that record their results with `polispec smoke record`. Today operators run their own smoke tests and record them (`docs/smoke.md`).
